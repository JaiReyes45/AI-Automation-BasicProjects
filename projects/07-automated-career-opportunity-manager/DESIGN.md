# CareerFlow workspace design

Direction: a quiet, modern personal workspace, with warm off-white canvas, white working surfaces, charcoal typography and restrained forest-teal actions. No gradients, decorative charts, marketing hero, or oversized metrics.

UI/UX Pro Max searches returned a relevant Minimalism & Swiss Style recommendation. The generated landing-page pattern was not appropriate for a CRM and was excluded; typography uses the existing locally available sans family. The functional style guidance informed this design; no off-topic generated master was persisted.

Tokens: ink #242C2A, accent #286656, secondary text #59625E, border #DDDFD9, canvas #F7F7F2. Use 8px corners, 48px action targets, 20/24/32px section spacing, 30px page titles. Semantic Material controls retain keyboard focus and labels. Light theme only.

Profile: separate personal details, internship, professional links, and document library. Fields are optional; validate populated email and HTTPS links. A save button commits profile fields; uploads and document links save separately. Saved profile data must never be described as disposable sample data.

## October 26 user-directed redesign

Use a Duolingo-inspired interaction style while retaining CareerFlow colors: friendly bold headings, generous rounded controls, tactile bottom-edge button depth, clear step-based progress and a compact icon/label navigation. No copied mascot, brand assets, fabricated streaks, XP or hiring-probability scores. Functional records and dates stay prominent. Palette remains forest green #286656, charcoal #242C2A, warm cream #F7F7F2 and white. Use 16-20px panel corners, 12-16px controls, 48px targets, visible focus, restrained motion and text wrapping at enlarged sizes. Profile avatar belongs at the top right; saved details are separate from editing and documents. Calendar and Assistant receive dedicated navigation tabs.

The prior editorial/dashboard search is superseded by the user's explicit Duolingo-inspired direction. Generated marketing landing-page sections are not applicable to this CRM. Implement the style with local Flutter controls and existing Material icons, with no remote fonts or mascot downloads.
