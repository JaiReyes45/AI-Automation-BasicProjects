## Field acceptance still open

The real pilot has three confirmed applications, eleven unresolved review messages and seventeen delivered eligible label jobs. A safely matched genuine employer follow-up has not advanced an application yet. Controlled progression is not a substitute for that field-acceptance observation. Unknown providers and ambiguous identities require manual review, and the bounded subject query is not a complete mailbox backfill.

This is a local hand-off release, not a public multi-user security certification. Whole-device disaster cutover has not been performed; the isolated data restore has. See HANDOFF.md for release scope and the operator guides for prerequisites.

## Installed-browser acceptance

The production Docker build was checked at desktop and 375×812. Review lists and decision controls, mobile navigation, task form validation and current sync status render correctly. A temporary synthetic application was used to save a dated task, complete it and reopen it through the browser. API readback confirmed the task date/status and unchanged submitted stage. The synthetic application, task, history and audit rows were removed afterward. Private QA screenshots are excluded from the release.

The final clean backup restored with 3 applications, 104 stored messages, 3 application events, 2 encrypted credential records and 7 workflows; tasks and audit were empty after fixture cleanup. No live database was replaced.

Sign-out returned 401 from both CRM and profile routes. The extracted release kit passed private settings generation and all-service Compose configuration validation with bundled web assets. This was a clean configuration check, not a replacement-device deployment or OAuth reconnection test. The release manifest and ZIP checksum are generated by scripts/package_release.py.
