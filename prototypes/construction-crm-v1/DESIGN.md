# Design

Operate-mode web interface for inspecting recorded evidence. The visual direction is a technical drawing board: warm paper surfaces, dark ink, thin construction rules and an orange incident accent. The scene uses precise geometric zones and tool markers, not claims about agent reasoning. Text hierarchy uses system sans for interface copy and monospace for identifiers and measurements. Borders define regions; controls retain clear labels and focus rings. Motion only reflects recorded events and respects reduced-motion preferences.

Tokens: paper `#f5f3eb`, surface `#fffef9`, ink `#172c2c`, muted `#586966`, rule `#cbd1c7`, incident `#a94b26`, action `#194d45`.

The construction dashboard uses the approved warm-paper palette with original pixel workers on an isometric tile site. A persistent work-order table and evidence inspector are the operable equivalents of canvas selection. Completed buildings require recorded acceptance. Diagnostic tooling remains at /diagnostics.
