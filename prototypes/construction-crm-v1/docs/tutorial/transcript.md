# Construction CRM tutorial

Illustrated UI walkthrough. All shown tasks and statuses are samples; real coding and provider effects are not recorded by this video. Narration uses the installed Windows Zira voice.

## 00:00 — Meet your engineer's desk

Construction CRM turns project work into a small construction site, with you as the engineer. You commission work, watch its evidence, and decide when a milestone is complete.

## 00:14 — Explore the recorded demo

The demo page plays recorded sample events. Switch between Build and Operate, or drag the replay slider. This preview starts no coding tasks and makes no AI calls.

## 00:28 — Launch the working dashboard

To use the working app, open PowerShell in the extracted source folder. Run npm run doctor, then npm start. Keep this terminal open and open its dashboard address.

## 00:42 — Connect your local runner

Click Connect and paste the local owner token printed in that terminal. This is your dashboard token. Keep HubSpot and GHL credentials on the server.

## 00:55 — Register the project

Give the project a name and enter the absolute folder path containing its code. For your first experiment, set Maximum model task starts to one, then register the project.

## 01:08 — Commission one small task

Enter a clear task, such as improving empty email validation while keeping valid submissions working. Choose a crew role, an available model, installed skills, and a milestone. Then commission and start.

## 01:24 — Watch evidence arrive

The work order moves through running and verification. Select Inspect to examine the task evidence. One model task runs by default. The worker animation itself uses no AI calls.

## 01:40 — Review each permission request

If a permission request appears, read the exact command or file change before deciding. Approve only that action, or decline. An approval does not grant permission for the whole session.

## 01:54 — Inspect before accepting

Review the changed files and any configured checks. Passing checks and your acceptance complete the milestone. In the work orders table, choose Accept work only when the result meets your criteria.

## 02:09 — Monitor the CRM in Operate

After the hosted backend is configured, Operate shows enquiries, HubSpot delivery, consultations, and reviews. A consultation can be confirmed while CRM delivery is retrying. Customers use your hosted enquiry page.

## 02:27 — Your first run

Start locally, register a project, and commission one small, reviewable task. Hosted deployment, the always on model, GHL key rotation, and owner acceptance remain pending. The installation guide explains setup.
