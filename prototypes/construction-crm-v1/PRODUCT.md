# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers inspecting local Codex runs. Assumption: the primary use is diagnosing a run after or during execution.

## Product Purpose

Record lifecycle and tool metadata and present evidence for inspecting agent work. Requested, available and observed skills remain distinct; tool activity does not prove skill causality.

## Capabilities and Constraints

Local-only service with bearer authentication. Metadata is the default; content capture is explicitly opted in, bounded and redacted. Replay follows recorded events. Synthetic demonstrations are labeled. The user controls launches and cancellation.

## Evidence on Hand

The recorder and synthetic fixture provide the only run evidence; no human pilot results are yet available.

## Accessibility & Inclusion

Keyboard access and reduced-motion support are required.

Construction CRM extends the recorder into a private engineer dashboard. Build mode commissions bounded real coding work; Operate mode observes separately hosted lead-to-consultation operations. Pixel motion is deterministic decoration and never generates model calls.
